Questions

Creator batch basics.

What is BlinkClip for?

BlinkClip is a macOS app for repeated video cleanup: trimming, cropping, converting, merging, adding intro or outro clips, and exporting batches without opening a full timeline editor.

See how BlinkClip fits

Is there a clip limit?

There is no fixed clip-count limit in the marketing promise. Practical batch size depends on your Mac, source files, storage, and the actions you run.

Does BlinkClip replace Final Cut, CapCut, Premiere, or DaVinci Resolve?

No. Keep your editor for story, pacing, color, and sound. Use BlinkClip when the same trim, crop, Add Intro action, merge, or conversion has to happen across many clips.

Does processing happen locally?

Core batch video processing happens on your Mac, so your files do not need to be uploaded for the main cleanup flow.

Read the privacy notes

Do I need to install FFmpeg separately?

No separate FFmpeg install is required for the public Mac app flow.

Is BlinkClip free?

The current public Mac build is free early access. Future Pro features may come later, but this site does not present a paid checkout.

What macOS version is required?

BlinkClip requires macOS 12.4 or newer.

How do updates work?

Install the DMG once, drag BlinkClip into Applications, and use in-app updates for future releases.

Open the Quick Start

Where do I get support?

Email blinkclip.app@gmail.com with install questions, bug reports, or feature requests.

Can BlinkClip process multiple videos at once?

Yes. Select multiple videos that need the same action, configure it once, and process the batch.

Run your first batch

Can I batch convert videos on Mac?

Yes. BlinkClip Convert applies one output setup across multiple selected video files.

Read the conversion guide

Can I batch compress videos?

Yes. Choose a practical compression preset and apply it to the videos in a selected batch.

Read the compression guide

Can I add the same intro to multiple videos?

Yes. Add Intro places one selected intro clip before every target video in the batch.
