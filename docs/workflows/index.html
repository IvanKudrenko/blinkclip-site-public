Run Reusable Video Workflows

Apply an ordered sequence of BlinkClip actions to a batch.

Open Quick StartSee all features

What it does

Workflow runs multiple actions in sequence for repeated creator jobs that always use the same cleanup order.

When to use it

  • Repeat a weekly publishing checklist
  • Standardize client delivery steps
  • Keep editor handoffs consistent

How to use it

  1. Select the videos

    Drag files into BlinkClip or use Select Videos to choose the batch.

  2. Choose Workflow

    Choose Workflow, arrange the actions in the order they should run, configure each action, and confirm the selected files.

  3. Process and review

    Start the batch, then open the processed files in Finder and check representative results.

Important behavior

Action order matters. Test a short batch before applying a new workflow to an important folder.
