Trim Videos in a Batch

Keep the same time range across multiple videos with one trim setup.

Open Quick StartSee all features

What it does

Trim keeps the section between a start time and an end time for every selected video.

When to use it

  • Remove a repeated countdown or blank opening
  • End recordings at the same timestamp
  • Clean up a folder of screen recordings or course lessons with matching timing

How to use it

  1. Select the videos

    Drag files into BlinkClip or use Select Videos to choose the batch.

  2. Choose Trim

    Choose Trim, then enter the start and end times for the range you want to keep.

  3. Process and review

    Start the batch, then open the processed files in Finder and check representative results.

Important behavior

The same timestamp range is applied to every selected video, so each file in the batch needs to suit that range.
