Release history

Latest public Mac release

v1.2August 9, 2026

More batch actions and output control

BlinkClip 1.2 adds focused video and audio actions plus clearer control over output defaults, frame rates, and repeated workflows.

Improvements

  • Change video speed across a batch with matching audio timing.
  • Compress videos with practical quality and file-size presets.
  • Change output resolution with fit, fill, stretch, and upscaling controls.
  • Extract audio to M4A, MP3, WAV, or the original stream format.
  • Mute videos or add a replacement or mixed audio track.
  • Insert a clip at a time, percentage, or position before the end.
  • Add image, GIF, or video overlays with placement, size, opacity, and timing controls.
  • Added Settings for appearance, output format, frame-rate handling, output folder, and completion behavior.
  • Improved frame-rate handling for mixed batches and exact broadcast rates.
  • Refined action selection, scrolling, workflow setup, and action icons.

Notes

  • Recommended for users who process repeated video and audio tasks in batches.
  • Includes updated Sparkle release files for in-app updates from BlinkClip 1.1.
  • Uses the same Apple Development signing process as previous BlinkClip releases.
v1.1May 6, 2026

Finder import and workflow polish

BlinkClip 1.1 makes the Mac release smoother to open from Finder, easier to aim at folders, and more reliable to move through repeated batch work without cluttering the main UI.

Improvements

  • Improved action naming so the main workflow reads more clearly.
  • Added Finder "Open With BlinkClip" importing so videos open directly into the app.
  • Added folder importing support in the native file picker.
  • Added Quick Look preview for faster clip inspection.
  • Cleaned up thumbnail presentation for easier scanning.
  • Improved the apply-to-all flow during crop work.
  • Added clearer output folder alerts before processing starts.
  • Improved crop workflow behavior and follow-through.
  • Polished the overall workflow and general app cleanup.

Notes

  • Keeps the main import UI focused on the Select Videos entry point.
  • Recommended for all users upgrading from earlier public builds.
  • Includes refreshed Sparkle update delivery for users coming from older public releases.
v1.0.3April 25, 2026

Stability update

BlinkClip 1.0.3 is a maintenance update focused on stability and reliability.

Improvements

  • Fixed an intermittent crash that could happen when importing or dragging multiple files into BlinkClip.
  • Improved thumbnail generation stability to reduce unexpected app quits in some cases.
  • Refreshed the installer and in-app update package for a smoother update experience.

Notes

  • Recommended for all users.
  • Includes updated Sparkle release files for in-app updates.
v1.0.2April 9, 2026

Release quality and installer polish

BlinkClip 1.0.2 focused on packaging, versioning, and update delivery so the public Mac release felt cleaner and more reliable to install and update.

  • Fixed app version metadata so BlinkClip reports 1.0.2 correctly.
  • Refreshed the Sparkle update package and appcast for in-app updates.
  • Restored the custom DMG installer design from the previous release.
  • Fixed the DMG Finder layout so the app and Applications icons appear in the correct positions.
  • Improved overall release packaging and install flow polish.
v1.0.1March 31, 2026

Automatic update added

BlinkClip added the update path that helps future public Mac builds stay current after the first manual install.

  • Added automatic in-app updates for future public macOS releases.
  • Added a visible Check for Updates entry inside BlinkClip.
v1.0.0March 30, 2026

First public build

The first public macOS build introduced the core batch quick-action flow.

  • Shipped the initial public Mac release.
  • Introduced batch quick actions for repeated video cleanup.
  • Added the first download page and early release distribution path.
